## Portfolio

Un portfolio moderne et responsive pour présenter mes projets, compétences et expériences, avec animations fluides, accessibilité soignée et performances optimisées.

### ✨ Fonctionnalités
- Sections: Accueil, À propos, Projets, Compétences, Contact
- Animations et micro-interactions
- Responsive (mobile → desktop)
- Formulaire de contact
- SEO de base (métadonnées, balises)
- Code propre et typé

### 🧰 Stack technique
- React + TypeScript
- Vite
- CSS (CSS Modules / utilitaires)
- Framer Motion (optionnel)

### 🚀 Démarrage
Prérequis: Node 18+

```bash
# Cloner
git clone https://github.com/<user>/<repo>.git
cd <repo>

# Installer
npm install

# Développement
npm run dev

# Build de production
npm run build

# Prévisualisation locale
npm run preview
```

### 📂 Structure 
- `src/sections`: sections du site (ex. `Contact.tsx`, `Projects.tsx`)
- `src/components`: composants UI réutilisables
- `src/assets`: images/icônes
- `src/styles`: styles globaux/utilitaires
